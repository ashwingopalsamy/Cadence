# Code of conduct

Cadence follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code and ideas rather than people, and keep discussion on topic. Harassment, personal attacks and publishing other people's private information are not tolerated.

Report unacceptable behaviour privately to the maintainer through GitHub (a private security advisory works if nothing else does). Reports are handled confidentially. Maintainers may remove comments, commits or issues that break these rules and may block repeat offenders.
